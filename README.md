# Hypixel Bedwars Statistic Tracker
---
This the Final project for CS222. This is a flutter application that allows Hypixel Bedwars players
to search for and compare with other players statistics using Hypixels real time API data. The goal 
of the flutter application is to be able to look up 2 different players name, compare their statistics
,see their games played, wins, loses, kills, deaths, K/D, W/L, and beds broken. The application also 
handles edge cases by displaying messages like, "No player found" when a username does not exist and
"No player statistics" when a player has no bedwars data. 

## Instructions
---
To be able to run this program you need to create a dart file called "secrets.dart" in the lib folder, then
within that dart file write "const String apiKey = 'api key goes here';". To be able to get the api 
key you must have a Minecraft Mojang account and create a Hypixel account then register for the api 
key at https://developer.hypixel.net/. If unable to access or gain the api key then email 
daniel.luengas@bsu.edu or joshua.halamka@bsu.edu.
